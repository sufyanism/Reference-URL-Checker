# Reference URL Checker
A simple tool to verify the validity of URLs in references or citations.

## Introduction
Reference URL Checker is a lightweight utility designed to help users quickly verify whether URLs in their references are active and accessible. It can be useful for researchers, students, and content creators to ensure the accuracy and reliability of their sources.

## Features
- Check the status of multiple URLs at once
- Identify broken or inaccessible links
- Generate a report of URL statuses
- Easy to use and extend

## Installation
To use this project, clone the repository:

```bash
git clone https://github.com/sufyanism/Reference-URL-Checker.git
cd Reference-URL-Checker
```
Ensure you have Python installed. The script does not require external dependencies, but it's recommended to use a virtual environment.

## Usage
Run the script to check URLs:
python app.py
